# Atari ST TT Falcon Guide 
v0.0000001 </br>

### Atari vs. Amiga </br>
were very similar, but with different Key changes. </br>

Atari ST = Amiga 500, basic model same Motorola 68k 000 CPU, same speed. </br>
there were different variants / upgrades to the ST,
STF = Floppy, STFM = Floppy + TV Modulator output. </br>
STE inprooved Blitted Graphics Chip. </br>
Mega 1,2,4 = 1MB, 2MB, 3MB "on a Desktop case" </br>
Mega STE improved Mega. </br>
[Atari TT 030](https://en.wikipedia.org/wiki/Atari_TT030) = Amiga 3000 by date 1990, and some features. </br>
Atari Falcon 030 = Amiga 1200 </br>

some differences </br>
STe versions had Blitter chip to accelerate moving graphics, </br>
Not included on the TT, </br>
TT had a different Graphics Shifter accelerator, </br>
Blitter was re-introduced again on the Falcon. </br>

Atari Falcon & TT are the Best & Last machines produced. </br>

**Differences:**  </br>
Flacon has Motorola DSP56001, used in many HW Synths, but can be used as Graphics co-processor / accelerator, </br>
TT has a Next Gen Expansion port: [VMEbus](https://en.wikipedia.org/wiki/VMEbus) </br>
Falcon CPU can be upgraded similar to Amiga, </br>
TT has soldered CPU. </br>

TT has optional [TenoxVGA](https://github.com/tenox7/tenoxvga) & [ATW800/2](https://www.geekdot.com/atw800_2/) HDMI output + Transputer FPGA emulation </br>

Atari ATW800 was a complete re-design, that included a standard Atari ST as helper machine. </br>
had Transputer CPU = optimized for Parallel processing, similar to GPU's today. </br>
with its own operating system, and developer SDK, Not compatible with standard C and ASM. </br>

ATW800/2 is a recreation board in FPGA, giving HDMI output + 1x Transputer CPU to a TT 030 machine using the VMEbus. </br>

TenoxVGA = Many Flicker Fixer options for Amiga </br>
Atari VME-card: ATW800/2 = zz9000 on the Amiga. </br>

Amiga was aiming at a higher Desktop Workstation Profesional Environment. </br>
Atari was more focused on "All-In-One" Keyboard sollution or Gaming console, </br>

Atari STE games had nice graphics, maybe similar to Amiga AGA. </br>

All Atari had a built-in MIDI I/O ports "Ready for Musicians". </br>
Amiga can be used with optional 3rd party Serial to Midi dongles. </br>

Atari TT has 4x 1MB ROM's runing at 8-Bits each = 32-Bits. </br>
Amiga 4000 has 2x ROM's at 16-Bits each. </br>

im surpriced how similar is: </br> 
Out of This world in all game platforms, very small differences, almost identical in different machines. </br>
